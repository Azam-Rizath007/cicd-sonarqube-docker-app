\# CI/CD Pipeline with SonarQube and Docker



This project demonstrates a complete CI/CD pipeline using:



\- GitHub

\- Jenkins

\- Maven and JUnit

\- SonarQube Quality Gate

\- Docker

\- DockerHub



\## Application



The Java application runs on port 8081 and displays:



CI/CD Pipeline is working successfully!



\## Pipeline stages



1\. Checkout

2\. Build and Test

3\. SonarQube Analysis

4\. Quality Gate

5\. Docker Build

6\. Docker Push

7\. Deploy
